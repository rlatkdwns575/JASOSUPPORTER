# 00. Project Brief

## Product Name

JasoSupporter

## One-Line Summary

JasoSupporter helps Korean job seekers structure their experiences once and reuse them across essays, portfolios, interviews, README drafts, and application records.

## Product Positioning

This app is not a simple self-introduction essay generator. It is an Experience-centered career content workspace.

Core flow:

```text
Experience Card
-> Master Essay
-> Portfolio Project
-> Interview Answer
-> Application Record
```

## Current App Capabilities

- Experience/spec input mode
- Master resume Q1-Q6 workspace
- Portfolio mode
- Gemini API-based AI responses
- Mode-specific prompts
- TXT / PDF / simple DOCX export
- PDF and image attachments
- Reference paste area
- Korean UI with ProductSans and blue/teal design direction

## Long-Term Direction

The app should evolve from input form + AI chat into a structured career knowledge base:

- Experience card database
- STAR fields per experience
- Essay questions linked to experiences
- Portfolio project cards
- Company-specific application records
- Reusable AI outputs with version history
- Exportable documents for each artifact

## Non-Goals

- Do not turn the product into a generic chatbot.
- Do not generate fake facts, results, or achievements.
- Do not replace the current app with a large rewrite before extracting responsibilities.
